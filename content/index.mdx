## ![정보 과부하](/illustrations/overload.png) 왜 만드는가

매일 AI 소식이 쏟아집니다. 새 모델, 기능 업데이트, 논문, 블로그. 다 따라가야 할 것 같은데 못 따라갑니다. 탭은 30개 열려 있고 북마크만 쌓이고, 안 보는 만큼 불안해집니다.

이 불안을 의지로 풀지 않습니다. 서비스로 풉니다. 코딩을 몰라도 AI에게 말로 시키면 됩니다. 단, 학습의 원리를 적용해서. 그냥 요약 봇이 아니라, 쓸수록 나를 점점 똑똑하게 만드는 구조를 만드는 겁니다.

## ![구조](/illustrations/gears.png) 오늘 만드는 것, 한 장으로

오늘 만드는 사이트는 상자 세 개로 끝납니다. 이 그림 하나가 워크숍 전체입니다. 앞의 두 상자는 화면으로 보고, 마지막 상자를 본인 노트북에서 직접 만듭니다.

<Flow>
  <FlowStep label="넣기 · input" title="깊이 읽기" meta="2·3페이지 👀 보기">
    정말 중요한 문서 하나를 다섯 가지 방식으로 다시 읽습니다. 많이 모으는 대신 하나를 두껍게.
  </FlowStep>
  <FlowStep label="고르기 · process" title="큐레이션" meta="4페이지 👀 보기">
    하루치 소식을 다 담지 않습니다. 기준 다섯으로 점수를 매겨 핵심 하나만 남깁니다.
  </FlowStep>
  <FlowStep label="받기 · output" title="뉴스레터" meta="5페이지 👀 보기 · 6페이지 ✋ 같이 하기" accent>
    골라진 소식이 매일 아침 내 인터넷 주소로 한 호씩 도착합니다.
  </FlowStep>
</Flow>

<Callout type="tip">
오늘의 목표 한 줄: 끝나면 본인 인터넷 주소에 내 관심사 뉴스레터 첫 호가 떠 있고, 내일 아침 두 번째 호가 알아서 도착합니다.
</Callout>

## ![체크](/illustrations/factcheck.png) 시작 전 준비물 3개

따라하기(6번 페이지)에서 쓰는 계정입니다. 지금 없어도 진행에 지장은 없지만, 미리 로그인해 두면 6번 페이지에서 10분을 아낍니다.

<Steps>
  <Step title="AI 도구 하나 (Claude · ChatGPT · Gemini 아무거나)">
    평소 쓰시는 걸 그대로 쓰면 됩니다. 오늘 시연은 Claude Cowork로 하지만, ChatGPT나 Gemini로도 똑같이 됩니다. 내 컴퓨터에 파일을 직접 만들어 주는 기능이 있으면 가장 매끄럽습니다.
  </Step>
  <Step title="GitHub 계정">
    템플릿을 가져올 때와 Vercel 가입에 씁니다. 없으면 [github.com](https://github.com)에서 이메일로 1분이면 됩니다. 코드는 볼 일이 없습니다.
  </Step>
  <Step title="Vercel 계정 (현장에서 만들어도 됩니다)">

  </Step>
</Steps>

## ![캘린더](/illustrations/calendar.png) 오늘의 흐름

페이지마다 첫 줄에 👀 또는 ✋ 표시가 있습니다. 👀는 화면만 보면 되는 시간, ✋는 본인 노트북에서 같이 하는 시간입니다. 3·5번 시연은 보기만 해도 됩니다. 손은 6번에서 씁니다.

| 페이지 | 여러분은 | 무엇을 |
|---|---|---|
| 1. 학습 에이전트 | 👀 보기 | 오늘 만드는 것을 넣기·고르기·받기 세 칸으로 보는 틀 |
| 2. 깊이 읽기 | 👀 보기 | 어려운 문서 하나를 여러 방식으로 읽는 이유 |
| 3. 시연 ① | 👀 보기 | 공식문서 링크 하나 → 다섯 가지 읽기 문서가 만들어지는 과정 |
| 4. 큐레이션 | 👀 보기 | 다 담지 않고 핵심 하나만 남기는 기준 |
| 5. 시연 ② | 👀 보기 | 관심사 뉴스레터 한 호가 발행되는 과정 |
| 6. 시작하기 | ✋ 같이 하기 | 본인 뉴스레터를 만들고, 인터넷에 올리고, 매일 자동으로 걸기 |

<Toggle title="오늘 나오는 말 6개 (막히면 여기로)">

| 말 | 뜻 |
|---|---|
| **학습 허브** | 오늘 만드는 결과물. 뉴스레터 지난 호 목록과 깊이 읽기 문서 모음이 한 사이트에 들어 있습니다. |
| **받아보기** | 내 관심사 AI 소식이 매일 아침 뉴스레터 한 호로 자동 도착하는 것. 세 칸 중 받기(output)입니다. |
| **깊이 읽기** | 어려운 문서 하나를 여러 렌즈로 다시 읽어 두껍게 이해하는 것. 세 칸 중 넣기(input)입니다. |
| **렌즈** | 같은 문서를 보는 방식 하나. 어원·한입요약·비유·퀴즈·전문번역 다섯이 기본입니다. |
| **큐레이션** | 하루치 소식을 다 담지 않고 기준으로 골라 핵심 하나만 남기는 것. 세 칸 중 고르기(process)입니다. |
| **Cowork · 에이전트 모드** | AI가 내 컴퓨터 폴더의 파일을 직접 만들고 고치는 모드. Claude는 Cowork, ChatGPT는 에이전트 모드가 이 역할입니다. 오늘의 모든 요청은 여기에 말로 합니다. |

</Toggle>

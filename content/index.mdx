## ![정보 과부하](/illustrations/overload.png) 왜 AI 학습 허브를 만드는가

매일 AI 소식이 쏟아집니다. 새 모델, 기능 업데이트, 논문, 블로그. 다 따라가야 할 것 같은데 못 따라갑니다. 탭은 30개 열려 있고 북마크만 쌓이고, 안 보는 만큼 불안해집니다.

이 불안을 의지로 풀지 않습니다. 서비스로 풉니다. 코딩을 몰라도 AI에게 말로 시키면 됩니다. 단, 학습의 원리를 적용해서. 그냥 요약 봇이 아니라, 쓸수록 나를 점점 똑똑하게 만드는 구조를 만드는 겁니다.

## ![캘린더](/illustrations/calendar.png) 오늘의 흐름

페이지마다 첫 줄에 👀 또는 ✋ 표시가 있습니다. 👀는 화면만 보면 되는 시간, ✋는 본인 노트북에서 같이 하는 시간입니다. 3·5번 시연은 보기만 해도 됩니다. 손은 6번에서 씁니다.

| 페이지 | 여러분은 | 무엇을 |
|---|---|---|
| 1. 학습 에이전트 | 👀 보기 | 오늘 만드는 것을 세 칸(input·process·output)으로 보는 틀 |
| 2. 깊이 읽기 | 👀 보기 | 어려운 문서 하나를 여러 렌즈로 읽는 이유 |
| 3. 시연 ① | 👀 보기 | 공식문서 링크 하나 → 렌즈 문서가 만들어지는 과정 |
| 4. 큐레이션 | 👀 보기 | 다 담지 않고 핵심 하나만 남기는 기준 |
| 5. 시연 ② | 👀 보기 | 관심사 뉴스레터 한 호가 발행되는 과정 |
| 6. 시작하기 | ✋ 같이 하기 | 본인 뉴스레터를 만들고, 인터넷에 올리고, 매일 자동으로 걸기 |

<Toggle title="오늘 나오는 말 6개 (막히면 여기로)">

| 말 | 뜻 |
|---|---|
| **학습 허브** | 오늘 만드는 결과물. 뉴스레터 아카이브 + 깊이 읽기 서재가 한 사이트에 들어 있습니다. |
| **받아보기** | 내 관심사 AI 소식이 매일 아침 뉴스레터 한 호로 자동 도착하는 것. output에 해당합니다. |
| **깊이 읽기** | 어려운 문서 하나를 여러 렌즈로 다시 읽어 두껍게 이해하는 것. input에 해당합니다. |
| **렌즈** | 같은 문서를 보는 방식 하나. 어원·한입요약·비유·퀴즈·전문번역 다섯이 기본입니다. |
| **큐레이션** | 24시간 소식을 다 담지 않고 기준으로 골라 핵심 하나만 남기는 것. process에 해당합니다. |
| **Cowork · 에이전트 모드** | AI가 내 컴퓨터 폴더의 파일을 직접 만들고 고치는 모드. Claude는 Cowork, ChatGPT는 에이전트 모드가 이 역할입니다. 오늘의 모든 요청은 여기에 말로 합니다. |

</Toggle>

## ![과녁](/illustrations/target.png) 오늘 워크숍에서 할 것

오늘은 AI 도구로 나만의 AI 학습 허브를 만드는 과정을 라이브로 봅니다. 내 관심사의 최신 소식을 매일 받아보고, 정말 중요한 문서는 여러 렌즈로 깊이 읽는 내 지식의 input 대시보드를 만드는 겁니다.

<Callout type="tip">
오늘의 목표: 어려운 문서 하나를 여러 렌즈로 깊이 읽고(input), 24시간 소식을 선정 기준으로 큐레이션해(process), 맞춤 뉴스레터 한 호로 받아본다(output). 끝나면 본인 인터넷 주소에 뉴스레터 첫 호가 떠 있습니다.
</Callout>

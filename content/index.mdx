## ![정보 과부하](/illustrations/overload.png) 왜 만드는가

매일 AI 소식이 쏟아집니다. 새 모델, 기능 업데이트, 블로그. 탭을 열어두고 북마크도 해둡니다. 그런데 나중에 다시 읽는 자료는 얼마나 될까요?

요즘은 한 달 사이 바뀌는 게 예전 1년 치입니다. 지금 뜨거운 소식도 한 달 뒤엔 안 중요한 경우가 많습니다. 그래서 매일 24시간치만 받습니다. 다 못 봐도 됩니다. 반복해서 나오는 것, 살아남는 것이 있으면 그때 알아봅니다.

슬랙 메시지로만 받으면 금방 사라집니다. 읽기 좋은 형태로, 내 주소에 쌓이게 만듭니다. 오늘 그걸 합니다.

## ![체크](/illustrations/factcheck.png) 준비물 4개 (워크숍 전에)

<Steps>
  <Step title="Claude Cowork 설치·로그인">
    오늘 시연과 실습은 Claude Cowork로 합니다. 노트북에 설치하고 로그인해 둡니다.
  </Step>
  <Step title="Cowork에 Gmail 커넥터 연결">
    설정 → 커넥터 → Gmail. 1단계에서 뉴스레터 링크를 내 메일로 보낼 때 씁니다. 회사 Google 계정으로 연결합니다.
  </Step>
  <Step title="GitHub 계정">
    2단계에서 내 저장소를 만들 때 씁니다. 없으면 [github.com](https://github.com)에서 무료로 가입합니다. 코드는 안 칩니다.
  </Step>
  <Step title="Cowork에 GitHub 커넥터 연결 (현장에서 해도 됩니다)">
    설정 → 커넥터 → GitHub. 미리 하면 2단계에서 10분을 아낍니다. 못 했으면 현장에서 함께 합니다.
  </Step>
</Steps>

## ![캘린더](/illustrations/calendar.png) 오늘의 흐름 (60분)

| 분 | 무엇을 | 여러분은 |
|---|---|---|
| 0–5 | 왜 나만의 뉴스레터인가 | 👀 보기 |
| 5–20 | **1단계** 첫 호를 아티팩트로 만들어 내 메일로 | ✋ 같이 |
| 20–50 | **2단계** 내 GitHub 저장소에 쌓고 Pages로 보기 | ✋ 같이 |
| 50–60 | **3단계** 응용 셋 미리보기, 내일 할 일 | 👀 보기 |

<Callout type="goal" title="오늘의 목표">
끝나면 세 가지가 있습니다. 받은편지함에 1호 링크. 내 주소 `https://내아이디.github.io/ai-newsletter/`에 1호. 그리고 내일 08:00 예약. 2단계에서 막힌 분은 "내 주소에 뭔가 뜬다"까지가 오늘 목표입니다.
</Callout>

<Toggle title="오늘 나오는 말 6개 (막히면 여기로)">

| 말 | 뜻 |
|---|---|
| **아티팩트** | Cowork가 만들어 화면에 띄우는 문서·페이지. 링크를 만들어 다른 사람에게 보낼 수 있습니다 |
| **커넥터** | Cowork를 Gmail·GitHub 같은 외부 서비스에 연결해 주는 설정. 한 번 연결하면 Cowork가 내 대신 메일을 보내고 파일을 올립니다 |
| **저장소** | GitHub에 만드는 내 폴더. 뉴스레터 파일이 여기 쌓입니다 |
| **템플릿 복사** | 남의 저장소를 내 것으로 통째로 복사하는 버튼(Use this template). 원본과 연결은 끊깁니다 |
| **GitHub Pages** | 저장소 안 파일을 인터넷 주소로 보여주는 GitHub 기능. 무료, Public 저장소만 |
| **스케줄** | Cowork에 "매일 8시에 이걸 해줘"라고 걸어두는 예약 |

</Toggle>

# 2. 어려운 문서를 여러 렌즈로 깊이 읽는다 (넣기)

<Callout type="note" emoji="👀">
읽다가 이해가 안 돼 미뤄둔 문서가 있나요? 그 문서를 떠올리며 읽어보세요. AI에게 어떤 설명을 더 요청하면 좋을지 살펴봅니다.
</Callout>

자료를 찾다 보면 읽을 것부터 늘어납니다. 북마크는 해뒀는데, 막상 내용을 설명하려니 잘 생각나지 않습니다. 그럴 때는 새 자료를 찾기 전에, 이미 읽은 글에서 무엇이 이해되지 않았는지 짚어봅니다.

오늘은 중요한 문서 하나를 여러 방식으로 읽어보려 합니다. 낯선 용어는 뜻과 유래를 묻습니다. 설명이 어려우면 익숙한 예시를 요청합니다. 읽고 나서는 퀴즈를 풀며 놓친 부분을 확인합니다. 이처럼 문서를 읽는 방식 하나를 여기서는 렌즈라고 부릅니다.

## ![돋보기](/illustrations/magnifier.png) 다섯 가지 렌즈

다섯 가지를 순서대로 읽을 필요는 없습니다. 지금 막힌 부분에 맞춰 골라보세요. 다음 페이지에서는 AI에게 이 형식으로 초안을 요청하고, 설명을 읽으며 더 물어볼 부분을 찾습니다.

<CardGrid columns={3}>
  <Card title="🔤 어원" vertical>
    낯선 용어의 뜻과 이름이 붙은 이유를 살펴봅니다. 확인할 수 없는 유래는 따로 표시합니다.
  </Card>
  <Card title="⚡ 한입요약" vertical>
    핵심을 5~7줄로 읽습니다. 전체 내용을 먼저 훑고, 자세히 볼 부분을 고릅니다.
  </Card>
  <Card title="🧒 비유로 쉽게" vertical>
    익숙한 일에 빗대어 설명을 들어봅니다. 원문과 어디까지 비슷한지도 확인합니다.
  </Card>
  <Card title="🧪 퀴즈" vertical>
    4~5문항을 직접 풀어봅니다. 답을 설명하기 어렵다면 그 부분을 다시 읽습니다.
  </Card>
  <Card title="📄 전문(번역)" vertical>
    한국어 번역으로 읽고, 뜻이 모호한 부분은 함께 실린 원문과 비교합니다.
  </Card>
</CardGrid>

<Callout type="tip">
읽다가 막히면 “여기가 이해가 안 돼. 내가 하는 일에 빗대어 다시 설명해줘”라고 요청해보세요. 다섯 가지 형식을 다 채우는 것보다, 본인이 이해하지 못한 부분을 찾아 묻는 게 중요합니다.
</Callout>

<Toggle title="근거가 궁금한 분만 (왜 여러 번 읽어야 하나)">

여러 관점과 맥락으로 복잡한 지식을 살펴본다는 점에서 인지 유연성 이론(Cognitive Flexibility Theory)을 참고할 수 있습니다. 다만 위의 다섯 가지 형식이 이론에서 정한 단계는 아닙니다. AI가 다섯 가지 문서를 만들어줬는지보다, 읽고 난 뒤 본인이 설명하거나 적용할 수 있는지를 확인해보려 합니다.

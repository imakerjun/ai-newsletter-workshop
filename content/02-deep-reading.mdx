# 2. 어려운 문서를 여러 렌즈로 깊이 읽는다 (넣기)

<Callout type="note" emoji="👀">
이 페이지는 보기만 하면 됩니다. 왜 자료를 더 모으지 않고 한 문서를 여러 번 읽는지, 이유 하나를 가져갑니다.
</Callout>

넣기를 늘리는 가장 흔한 오해는 자료를 더 모으는 겁니다. 탭을 30개 열고 북마크를 쌓습니다. 그런데 정작 내 것이 되는 건 없습니다. 읽은 게 아니라 모으기만 했기 때문입니다.

더 빠른 길은, 정말 중요한 문서 하나를 여러 방식으로 다시 읽는 겁니다. 같은 글이라도 단어의 뿌리로 볼 때와 일상 비유로 볼 때 이해되는 깊이가 다릅니다. 이렇게 문서를 보는 방식 하나를 렌즈라고 부르고, 렌즈를 바꿔 같은 문서를 다시 읽는 걸 깊이 읽기라고 부릅니다.

## ![돋보기](/illustrations/magnifier.png) 다섯 가지 렌즈

순서가 아니라 골라 쓰는 다섯 가지입니다. 다음 페이지 시연에서 AI에게 시켜 이 다섯 개를 한 번에 만듭니다.

<CardGrid columns={3}>
  <Card title="🔤 어원" vertical>
    핵심 용어와 이름의 유래. 말의 뿌리를 알면 개념이 덜 미끄러집니다.
  </Card>
  <Card title="⚡ 한입요약" vertical>
    핵심을 5~7줄로. 바쁠 때 이것만 봐도 흐름이 잡힙니다.
  </Card>
  <Card title="🧒 비유로 쉽게" vertical>
    일상 비유로 감 잡기. 전문용어 없이 감이 오는 데까지.
  </Card>
  <Card title="🧪 퀴즈" vertical>
    4~5문항 자가 점검. 읽었다고 착각한 부분이 드러납니다.
  </Card>
  <Card title="📄 전문(번역)" vertical>
    원문 전체를 한국어로. 영어 원문은 접어서 병기합니다.
  </Card>
</CardGrid>

<Callout type="tip">
이 다섯은 정답이 아니라 출발점입니다. 나에게 잘 맞는 읽기 방식으로 렌즈를 바꾸거나 더하면 됩니다. 핵심은 하나, 같은 문서를 여러 방식으로 다시 보는 것입니다.
</Callout>

<Toggle title="근거가 궁금한 분만 (왜 여러 번 읽어야 하나)">

인지 유연성 이론(Cognitive Flexibility Theory)이 답을 줍니다. 어렵고 복잡한 내용은 한 번, 한 방향으로만 읽으면 지나치게 단순해져 버립니다. 같은 자료를 여러 맥락과 관점에서 가로질러 다시 밟아야 비로소 다른 상황에도 옮겨 쓸 수 있는 이해가 생깁니다. 렌즈를 바꿔 한 문서를 다시 읽는 게 바로 이 가로지르기입니다.

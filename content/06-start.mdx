# 6. 시작하기

<Callout type="tip" emoji="✋">
여기부터 같이 합니다. 노트북에서 쓰시는 AI 도구를 엽니다(Claude는 Cowork 탭, ChatGPT는 에이전트 모드). 단계마다 끝에 "이렇게 보이면 성공" 줄이 있습니다. 그 모습이 안 나오면 손을 들어 주세요. 옆 사람이 앞서가도 상관없습니다.
</Callout>

## ![설명](/illustrations/explain.png) 따라하기 세 단계

전부 AI에게 말로 시키는 작업입니다. 아래 상자들은 코드가 아니라 그냥 한국어 문장입니다. 오른쪽 위 복사 버튼을 누르고 AI 입력창에 붙이면 됩니다. 어떤 AI 도구를 쓰든 같습니다. 단계마다 무엇을 위한 단계인지 먼저 짚었습니다.

### 1단계 — 페이지로 먼저 확인

무엇을 위한 단계인가요. 결과물부터 눈으로 봅니다. 코드 없이 템플릿을 가리켜 한 번 만들어 보고, 내가 원하던 모습이 맞는지 확인하는 겁니다.

AI 도구에서 새 폴더를 하나 열고(이름은 `ai-newsletter` 정도면 됩니다), 이렇게 요청합니다.

```text
https://github.com/imakerjun/ai-newsletter-template 이 템플릿을 활용해서,
지난 1주일간 있었던 AI 소식을 페이지로 만들어 주세요.
```

이어서 관심사를 내 것으로 바꿉니다. 이 한 줄이 "나만의"를 만듭니다. 탭은 2~5개가 적당합니다.

```text
AGENT.md의 관심사 탭을 이렇게 바꿔줘.
1) AI 최신 소식 (24시간)  2) {내 직무}를 위한 AI 활용  3) {개인 관심사}
나머지 탭은 지우고, 바꾼 관심사로 페이지를 다시 만들어줘.
```

중괄호 `{ }` 부분은 본인 것으로 바꿔 쓰고, 중괄호 기호는 지웁니다. 예: `{내 직무}` → `마케터`.

<Callout type="tip">
이렇게 보이면 성공: AI가 만든 파일을 브라우저로 열어 보여주고, 뉴스레터 첫 화면 상단에 내가 적은 관심사 탭이 보입니다. 아직 인터넷 주소는 없습니다. 내 컴퓨터 안에서만 보이는 미리보기입니다.
</Callout>

### 2단계 — Vercel로 인터넷에 올리기

무엇을 위한 단계인가요. 1단계 페이지는 아직 내 작업 공간에만 있습니다. 인터넷 주소로 띄워야 어디서나 열어보고 매일 자동으로 받아볼 수 있습니다. Vercel은 그 주소를 무료로 만들어 주는 서비스입니다. 오늘 가장 클릭이 많은 단계입니다. 천천히 하면 됩니다.

이 단계에서 처음 보는 말 넷입니다. 이것만 알면 됩니다.

| 말 | 뜻 |
|---|---|
| **배포** | 내 페이지를 인터넷에 올려, 링크로 아무나 볼 수 있게 만드는 것 |
| **Vercel** | 페이지를 올려두는 인터넷 공간. 무료이고 AI가 직접 올려줄 수 있어 편함 |
| **커넥터** | AI 도구를 Vercel 같은 외부 서비스에 연결해 주는 설정 메뉴 |
| **토큰** | 내 계정 대신 작업하게 해주는 비밀 출입증. 비밀번호처럼 다룸 |

1. [vercel.com](https://vercel.com)에서 계정을 만듭니다. GitHub 계정으로 바로 가입할 수 있습니다.
2. 쓰시는 AI 도구의 설정에서 Vercel 커넥터(연동)를 추가합니다. AI가 내 Vercel에 배포할 수 있게 연결하는 단계입니다.
3. [Vercel 토큰 페이지](https://vercel.com/account/settings/tokens)에서 토큰을 만들어 AI에 붙여넣습니다. AI에게 주는 출입증이라고 보면 됩니다.
4. AI에 이렇게 요청합니다.

```text
방금 만든 페이지를 Vercel로 배포해줘. 끝나면 공개 주소를 알려줘.
```

<Callout type="danger">
토큰은 비밀번호와 같습니다. 화면을 공유 중이면 토큰 페이지를 열기 전에 공유를 잠깐 멈추고, 슬랙·채팅·이 사이트 어디에도 붙여넣지 않습니다. 실수로 노출됐다면 토큰 페이지에서 그 토큰을 삭제하고 새로 만들면 됩니다.
</Callout>

<Callout type="tip">
이렇게 보이면 성공: `https://….vercel.app` 형태의 주소가 나오고, 휴대폰에서 그 주소를 열어도 내 뉴스레터가 보입니다. 이 주소를 동료에게 보내도 됩니다.
</Callout>

### 3단계 — 매일 아침 자동 발행 (스케줄)

무엇을 위한 단계인가요. 여기까지는 한 번 만든 겁니다. 스케줄을 걸어두면 손대지 않아도 매일 아침 새 소식으로 새 호가 알아서 만들어져 도착합니다. 이게 받아보기의 완성입니다.

쓰시는 AI 도구의 스케줄(예약 작업) 기능으로 이렇게 겁니다. Claude는 스케줄, ChatGPT는 작업(Tasks)이 같은 기능입니다.

```text
매일 아침 8시에, AGENT.md 사양대로 지난 24시간 AI 소식으로 새 뉴스레터를 만들고,
Vercel로 배포한 다음, 공개 주소를 나에게 보내줘. 과거 호는 건드리지 마.
```

<Callout type="tip">
이렇게 보이면 성공: 스케줄 목록에 "매일 08:00" 항목이 하나 보입니다. 내일 아침 링크가 오면 열어서 새 호가 지난 호 목록 맨 앞에 붙었는지 확인합니다. 오늘 확인할 방법은 없습니다. 내일 아침이 검증입니다.
</Callout>

### (선택) 어려운 문서 하나를 깊이 읽기로

3번 페이지 시연을 본인 문서로 해봅니다. 같은 폴더에서 링크 하나만 주면 됩니다. 공식문서, 긴 블로그 글, 논문 아무거나 됩니다.

```text
이 링크를 깊이 읽기 렌즈 문서로 만들어줘:
{문서 URL}
```

<Toggle title="막혔을 때 (자주 걸리는 지점 5개)">

| 상황 | 해볼 것 |
|---|---|
| 파일을 만들어 주는 기능이 안 보인다 | Claude는 데스크톱 앱의 Cowork 탭, ChatGPT는 에이전트 모드입니다. 앱을 최신으로 업데이트합니다. 없으면 옆 사람 화면을 같이 봐도 됩니다. |
| 1단계에서 템플릿을 못 가져온다 | 링크를 그대로 다시 붙이고 "이 GitHub 주소의 파일들을 이 폴더로 가져와서"라고 한 문장 앞에 붙입니다. |
| Vercel 커넥터가 목록에 없다 | AI 도구의 설정 → 커넥터(연동)에서 검색합니다. 그래도 없으면 토큰만 발급해서 "이 Vercel 토큰으로 배포해줘"라고 붙여 넣어도 됩니다. |
| 배포는 됐는데 페이지가 비어 있다 | 1단계 미리보기가 정상이었는지 먼저 확인합니다. 정상이면 "방금 만든 폴더 전체를 다시 배포해줘"라고 시킵니다. |
| 스케줄 메뉴를 못 찾는다 | 스케줄(예약 작업) 메뉴는 도구·버전마다 위치가 다릅니다. 진행자 화면을 같이 봅니다. 못 찾아도 2단계까지 끝났으면 오늘 목표는 달성입니다. |

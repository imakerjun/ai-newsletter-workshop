# 6. 시작하기

<Callout type="tip" emoji="✋">

## ![설명](/illustrations/explain.png) 따라하기 세 단계

아래 상자에는 AI에게 전달할 요청을 적어두었습니다. 오른쪽 위 복사 버튼으로 가져와 본인 상황에 맞게 바꿉니다. AI가 되묻는 내용에 답하고, 결과를 보면서 다음 요청을 이어갑니다. 도구마다 지원하는 기능과 화면은 다를 수 있습니다.

### 1단계 · 페이지로 먼저 확인

먼저 읽어볼 수 있는 초안을 만듭니다. 어떤 소식이 담겼는지, 설명이 내게 도움이 되는지 확인하는 단계입니다. 처음부터 원하는 모습이 나오지 않아도 괜찮습니다.

AI 도구에서 새 폴더를 하나 열고(이름은 `ai-newsletter` 정도면 됩니다), 이렇게 요청합니다.

```text
https://github.com/imakerjun/ai-newsletter-template 이 템플릿을 활용해서,
지난 1주일간 있었던 AI 소식으로 뉴스레터 초안을 만들어 주세요.
원문 링크와 발행일을 붙이고, 내용을 확인할 수 있게 미리보기를 열어주세요.
아직 공개하거나 배포하지 마세요. 필요한 정보가 있으면 먼저 물어봐 주세요.
```

이어서 관심사를 바꿉니다. 어떤 일을 하고 무엇이 궁금한지 알려줍니다. 처음에는 탭 2~5개로 시작해 봅니다.

```text
나는 {내 직무}이고, {지금 알아보거나 해결하고 싶은 일} 때문에 이 뉴스레터를 읽으려고 해.
AGENT.md의 관심사 탭을 이렇게 바꿔줘.
1) AI 최신 소식 (24시간)  2) {내 직무}를 위한 AI 활용  3) {개인 관심사}
나머지 탭은 지우고, 바꾼 관심사로 초안을 다시 만들어줘.
소식을 고른 이유도 함께 보여줘. 내가 확인한 뒤에 발행할게.
```

중괄호 `{ }` 부분은 본인 것으로 바꿔 쓰고, 중괄호 기호는 지웁니다. 예: `{내 직무}` → `마케터`.

초안을 읽고 원문 링크도 열어봅니다. 관심사와 맞지 않는 소식이나 이해하기 어려운 설명이 있다면 그 부분을 짚어줍니다. AI가 수정한 뒤에는 바뀐 부분을 다시 확인합니다.

<Callout type="tip">
이렇게 보이면 성공: 브라우저 미리보기에서 내가 적은 관심사 탭이 보입니다. 소식의 원문과 발행일을 확인할 수 있고, 고쳐달라고 한 내용도 반영돼 있습니다. 아직 다른 사람에게 공개하기 전입니다.
</Callout>

### 2단계 · Vercel로 인터넷에 올리기

1단계에서 확인한 초안을 인터넷에 올립니다. 공개 주소가 생기면 휴대폰에서도 열고 다른 사람에게 보낼 수 있습니다. 이번에는 Vercel을 사용합니다. 계정과 연결 설정이 필요한 단계라 천천히 진행합니다.

이 단계에서 처음 보는 말 넷입니다. 이것만 알면 됩니다.

| 말 | 뜻 |
|---|---|
| **배포** | 내 페이지를 인터넷에 올려, 링크로 아무나 볼 수 있게 만드는 것 |
| **Vercel** | 페이지를 인터넷에 올리고 공개 주소를 만드는 서비스 |
| **커넥터** | AI 도구를 Vercel 같은 외부 서비스에 연결해 주는 설정 메뉴 |
| **토큰** | 내 계정 대신 작업하게 해주는 비밀 출입증. 비밀번호처럼 다룸 |

1. [vercel.com](https://vercel.com)에서 계정을 만듭니다. GitHub 계정으로 바로 가입할 수 있습니다.
2. 쓰시는 AI 도구가 Vercel 커넥터(연동)를 지원하면 설정에서 추가합니다. AI가 내 Vercel에 배포할 수 있게 연결하는 단계입니다.
3. 연결 과정에서 토큰이 필요하다면 [Vercel 토큰 페이지](https://vercel.com/account/settings/tokens)에서 만들 수 있습니다. 토큰을 저장할 설정 위치는 진행자와 함께 확인합니다. 일반 대화창에는 붙여 넣지 않습니다.
4. 초안을 읽고 공개할 내용이 맞는지 확인한 뒤, AI에 이렇게 요청합니다.

```text
확인한 이 초안으로 첫 호를 발행하고 Vercel에 배포해줘.
끝나면 공개 주소를 알려줘. 과거 호가 있다면 그대로 둬.
```

토큰은 비밀번호와 같습니다. 화면을 공유 중이면 토큰 페이지를 열기 전에 공유를 잠깐 멈추고, 슬랙·채팅·이 사이트 어디에도 붙여넣지 않습니다. 실수로 노출됐다면 토큰 페이지에서 그 토큰을 삭제하고 새로 만들면 됩니다.
</Callout>

<Callout type="tip">
이렇게 보이면 성공: `https://….vercel.app` 형태의 주소가 나오고, 휴대폰에서 그 주소를 열어도 내 뉴스레터가 보입니다. 이 주소를 동료에게 보내도 됩니다.
</Callout>

### 3단계 · 매일 아침 자동 발행 (스케줄)

여기까지 첫 호를 만들었습니다. 다음에는 같은 기준으로 새 호를 만드는 작업을 예약합니다. 첫 호를 고치면서 정한 기준은 `AGENT.md`에 남깁니다. 자동 발행을 켠 뒤에도 소식이 목적에 맞게 골라지는지 확인하고 기준을 다듬습니다.

사용하는 AI 도구에서 예약 실행과 배포를 지원하는지 먼저 확인합니다. 지원하는 환경에서는 아래처럼 요청합니다. 아직 매번 내용을 확인하고 싶다면 자동 발행 대신 초안만 받아보도록 바꿔도 됩니다.

```text
첫 호를 확인했고, 같은 기준으로 다음 호부터 자동 발행하려고 해.
매일 아침 8시에 AGENT.md 기준으로 지난 24시간 AI 소식의 새 호를 만들고,
Vercel에 배포한 뒤 공개 주소를 나에게 보내줘. 과거 호는 그대로 둬.
예약에 적용되는 시간대를 확인하고, 실행 기록을 어디서 보는지 알려줘.
출처 확인이나 배포에 실패하면 발행을 멈추고 어떤 문제가 있는지 알려줘.
```

<Callout type="tip">
이렇게 보이면 성공: 예약 목록에 원하는 시간대의 "매일 08:00" 항목이 보입니다. 시험 실행을 지원하면 오늘 한 번 실행해 새 호와 링크를 확인합니다. 실제 예약 시각에 실행되는지는 내일 아침 실행 기록과 받은 링크로 확인합니다.
</Callout>

### (선택) 어려운 문서 하나를 깊이 읽기로

3번 페이지 시연을 본인 문서로 해봅니다. 공식 문서나 긴 글 중 이해하고 싶은 자료를 고릅니다. 링크와 함께 읽는 목적, 어려웠던 대목을 알려줍니다.

```text
이 링크를 깊이 읽기 렌즈 문서로 만들어줘:
{문서 URL}
나는 {이 문서를 읽는 목적} 때문에 읽고 있고, {잘 이해되지 않는 부분}이 어려워.
원문을 확인할 수 없는 부분은 추측하지 말고 알려줘.
```

<Toggle title="막혔을 때 (자주 걸리는 지점 5개)">

| 상황 | 해볼 것 |
|---|---|
| 파일을 만들어 주는 기능이 안 보인다 | 사용 중인 도구와 계정에서 파일 작업을 지원하는지 진행자와 확인합니다. 바로 해결하기 어려우면 옆 사람과 함께 결과를 읽고 고칠 부분을 찾아봅니다. |
| 1단계에서 템플릿을 못 가져온다 | 링크를 그대로 다시 붙이고 "이 GitHub 주소의 파일들을 이 폴더로 가져와서"라고 한 문장 앞에 붙입니다. |
| Vercel 커넥터가 목록에 없다 | AI 도구의 설정에서 커넥터나 연동 메뉴를 확인합니다. 지원하지 않으면 진행자와 사용할 연결 방법을 정합니다. 토큰을 대화창에 붙여 넣어 해결하지 않습니다. |
| 배포는 됐는데 페이지가 비어 있다 | 1단계 미리보기가 정상이었는지 먼저 확인합니다. AI에게 미리보기와 공개 주소의 차이를 알려주고, 배포할 파일과 설정을 확인해달라고 요청합니다. |
| 스케줄 메뉴를 못 찾는다 | 예약 기능을 지원하는지 진행자와 확인합니다. 예약까지 연결하지 못했다면 첫 호의 공개 주소와 남은 설정을 적어둡니다. |

</Toggle>
